# Smart Display 📺

**A modern digital signage and announcement management system built with React and Vite.**

Smart Display is a web-based application designed to display company announcements, safety notices, live weather updates, and real-time information on TVs and monitors.

## ✨ Features

- 📢 Dynamic company announcements
- 🛡️ Animated safety and employee badge notifications
- 🌤️ Live weather updates using the Open-Meteo API
- 🕒 Real-time clock and date
- 📋 Announcement management with add and delete functionality
- 📺 Responsive digital signage layout
- 🔄 Automatic weather refresh
- 📱 Responsive design for different screen sizes

## 🎯 Project Goals

- Build a professional digital signage platform.
- Create an administrator dashboard for managing content.
- Display real-time information on office screens.
- Develop a full-stack application with a backend API and database.
- Support multiple displays and remote content management in future versions.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/OmerMasih/smart-display.git
```

Navigate to the project directory:

```bash
cd smart-display
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL displayed in your terminal.
